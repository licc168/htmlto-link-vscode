# Quick Static Site Publish

一个面向前端开发者的静态网站一键发布插件，可以直接从 VS Code、Cursor、Trae 中选择本地站点文件夹，在可视化面板中完成发布，并立即获得公开访问链接。

## 精准定位

- 面向本地静态网站和前端演示项目
- 从文件夹直接发布，不需要手动压缩和上传
- 自动识别根目录 HTML 文件并选择入口
- 支持游客临时发布和 Token 长期发布
- 发布成功后立即返回公开访问链接

## 核心体验

- 选择本地文件夹后即可在面板中一键发布
- 自动识别入口 HTML 文件并列出可选项
- 支持游客部署，适合快速分享临时页面
- 支持保存 Token，便于长期管理和重复发布
- 部署成功后自动返回 URL，可直接复制或打开

## 入口方式

- 命令面板中执行 `静态网站一键发布: 打开发布面板`
- 在资源管理器中右键文件夹后执行发布
- 面板内统一完成文件夹选择、入口 HTML 选择、Token 配置和发布结果查看

## 当前定位

当前版本聚焦于“静态网站发布”这一个核心任务，不包含：

- Markdown 编辑器
- 模板选择
- 页面预览面板
- 用户中心能力

## 开发

```bash
npm install
npm run build
```
